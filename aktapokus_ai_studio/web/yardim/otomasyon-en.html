What is an automation?

A trigger starts a task; when it finishes you can publish to a site and get a Telegram notification. It is all one flow, built on the canvas.

Build your first automation

  1. On Settings > Automations press + Add template.
  2. Click the Task node and write the job in plain text. Pick a model if you like; if empty, the project's role setting is used.
  3. If needed, add ↓ to read web pages, ⇪ to publish, + for a notification.
  4. Choose the trigger: manual or timer (every N minutes, daily at X, days of the week).
  5. Save with ✓, then try Run now.

Nodes

Arrows only go one way: trigger → (fetch web) → task → (publish | notification). A flow has one trigger and one task.

You can use variables in task and notification texts: {tarih} {saat} {proje} {dal} · in notifications also {durum} {yanit} {yayin}

Example: a news page

The timer runs every morning. Fetch web reads the pages, the task writes the page from the news, Publish sends the folder to the site, the notification writes the result to your phone.

In the Publish node fill in: source folder (the page folder in the project), target repository (e.g. bmenderes/bmenderes.github.io), folder in the repository (e.g. haberler). In an automation the folder name is required.

Approval and permissions

By default every run first makes a plan and waits for your approval. Nothing runs until you approve.

For an automation you trust, allow it to run without approval in Settings > Permissions. An unattended publish still goes through the safety gate.

How publishing stays safe

Aktapokus publishes, not the agent. The agent cannot reach GitHub. Every publish goes through this gate:

If there is a high or medium risk finding (keys, personal data) or the AI review cannot run, an automatic publish stops and nothing is sent. When publishing by hand you see the findings and decide.

When publishing by hand, if you leave Folder in the repository empty, the files are added to the repository root (like a personal index page). Nothing is deleted; files with the same name (e.g. index.html) are replaced, and you are asked first. If you give a folder name, that folder's previous content is replaced.

Connect Telegram

One-time setup. The bot only talks to you.

  1. In Telegram send /newbot to @BotFather; it gives you a token (keep it secret).
  2. In Aktapokus: Settings > Telegram > paste the token > Start.
  3. Say New pairing code, then send the message shown (e.g. /eslestir ab12cd34) to your bot.

Two GitHub accounts

Aktapokus can work with more than one GitHub account. On Settings > Accounts > GitHub press Add account and enter the code.

You do not pick the account: if the repository owner has the same name as an added account, that account is used. Otherwise (e.g. another organization's repository) the default account is used.

Limits

  • It runs while the app is open. Times missed while closed are recorded as missed.
  • One task runs per project at a time; a colliding trigger is skipped.
  • At most 20 automations, shortest interval 5 minutes.
  • Notifications go to Telegram only; if the bot is not running nothing is sent and the history says so.
  • Every run shows in Settings > Automations > Run history.
